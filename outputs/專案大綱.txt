智匯數據簡報神器是一套讓使用者用一段自然語言指令加一份多工作表 Excel，就能自動產出簡報的系統。產出的簡報套用台新新光金控模板，每張圖表都是 PowerPoint 原生可編輯物件而非圖片拼貼，右鍵選擇編輯資料即可開啟內嵌工作表，並同步輸出一份與圖表逐頁對應的稽核 Excel，數字百分之百可追溯回原始資料。目前已完成的功能包括：市占率、排名、成長率與趨勢外推等指標的自動計算；長條、折線、圓餅、散點、雙軸與熱力圖等原生圖表與表格生成；稽核 Excel 的同步輸出；可透過命令列、網頁介面或非同步工作 API 觸發的端到端流程；以及可在雲端與地端模型間切換的抽換層，並已用 Gemini 等真實模型完成端到端實跑驗證。尚未完成的是自動寄送信件與 DeckSpec 一鍵重生成兩項功能。技術上，資料計算全部使用 pandas、openpyxl 與 scikit-learn 走確定性程式碼，不假手模型；簡報生成使用 python-pptx，所有圖表統一經由單一入口產生，確保圖表快取值與內嵌工作簿天生一致；模型呼叫層是相容 OpenAI 介面的輕量封裝，支援 Gemini、Bedrock、vLLM 與 Ollama 等多種後端；服務層以 FastAPI 提供非同步工作模式，前端用 React 建置，並以 Docker Compose 部署。核心設計原則是模型只負責意圖解析、洞察敘事與信件摘要，絕不參與任何數值計算，敘事中的數字一律以佔位符代入並標示黃色以便追溯，資料不足以支撐的指標則由防呆機制擋下不予產出。目前單元測試共 202 項全數通過，真實模型端到端的三方數值比對 71 項也全數一致。
